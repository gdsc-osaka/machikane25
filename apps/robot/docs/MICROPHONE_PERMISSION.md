# macOSマイク権限の設定ガイド

## 問題

macOSでは、アプリケーションがマイクにアクセスするには明示的な権限が必要です。
常時リスニングシステムを使用する際、以下のような症状が出る場合はマイク権限の問題です：

- ✅ ターミナルで直接実行すると音声が取れる
- ❌ VSCodeや他のアプリから実行すると音声が取れない（RMS = 0.0000）
- ❌ `Audio Unit: cannot do in current context` エラーが出る

## 解決方法

### 1. システム設定でマイク権限を確認

#### ステップ1: マイク権限設定を開く

**コマンドで開く（推奨）**:
```bash
open "x-apple.systempreferences:com.apple.preference.security?Privacy_Microphone"
```

**または手動で開く**:
1. 「システム設定」を開く
2. 「プライバシーとセキュリティ」→「マイク」

#### ステップ2: 以下のアプリに権限を付与

- ✅ **ターミナル** (Terminal.app)
- ✅ **zsh** (シェル)
- ✅ **bash** (シェル)
- ✅ **Python** (表示されていれば)
- ✅ **Visual Studio Code** (VSCodeを使用している場合)
- ✅ **iTerm** (iTermを使用している場合)

#### ステップ3: ターミナル/VSCodeを再起動

設定変更後、必ずアプリケーションを完全に終了して再起動してください。

---

### 2. マイク権限をリセット

設定が上手くいかない場合、権限をリセットして再度許可します：

```bash
# マイク権限をリセット
tccutil reset Microphone

# スクリプトを実行すると権限要求ダイアログが表示される
python3 src/main.py
```

**注意**: リセットすると、すべてのアプリのマイク権限がクリアされます。

---

### 3. 直接ターミナルから実行

VSCodeのターミナルではなく、macOSの「ターミナル.app」から直接実行:

```bash
cd /Users/litchi/Documents/machikane25/apps/robot
python3 src/main.py
```

## 確認方法

### マイク権限が正しく設定されているか確認

```bash
# オーディオデバイスを確認
python3 check_audio_devices.py

# シンプルな録音テスト
python3 test_whisper_simple.py
```

**期待される結果**:
- RMS音量が **0.01以上** になる（話しているとき）
- 文字起こし結果が正しく表示される

**問題がある場合の結果**:
- RMS音量が **0.0000** のまま
- 「録音データなし」または「音声なし」と表示される

## トラブルシューティング

### 問題1: マイク権限を付与したのに音声が取れない

**原因**: ターミナル/VSCodeを再起動していない

**解決策**:
1. ターミナルまたはVSCodeを完全に終了
2. 再度開いてスクリプトを実行

---

### 問題2: マイク権限の設定にターミナルが表示されない

**原因**: 一度も権限要求が発生していない

**解決策**:
```bash
# 権限要求を発生させる
python3 -c "import sounddevice as sd; sd.rec(100, samplerate=16000, channels=1)"
```

実行後、権限要求ダイアログが表示されるので「許可」をクリック。

---

### 問題3: 外部マイクが接続されていない

**症状**: デフォルト入力デバイスが「BlackHole 2ch」になっている

**解決策**:
1. **外部マイクを接続**、または
2. **システム設定** → **サウンド** → **入力**で正しいマイクを選択

確認コマンド:
```bash
# システムのオーディオデバイスを確認
system_profiler SPAudioDataType
```

---

### 問題4: 「Audio Unit: cannot do in current context」エラー

**原因**:
- マイク権限がない
- 他のアプリケーションがマイクを使用中
- オーディオデバイスの競合

**解決策**:
1. マイク権限を確認（上記参照）
2. 他のマイク使用アプリを終了（Zoom、Skype、Discord等）
3. システムを再起動

---

## 開発時の推奨設定

### VSCodeで開発する場合

1. **VSCodeにマイク権限を付与**
   - システム設定 → プライバシーとセキュリティ → マイク → Visual Studio Code ✅

2. **VSCodeの統合ターミナルで実行**
   ```bash
   python3 src/main.py
   ```

3. **それでもダメな場合は外部ターミナルから実行**
   - ターミナル.appを開く
   - プロジェクトディレクトリに移動
   - `python3 src/main.py` を実行

## まとめ

常時リスニングシステムを使用するには、必ず以下を確認：

1. ✅ **ターミナルまたはVSCodeにマイク権限を付与**
2. ✅ **アプリケーションを再起動**
3. ✅ **正しいマイクデバイスが選択されている**
4. ✅ **マイク権限の確認コマンドで動作確認**

これらを確認しても動作しない場合は、Issueを作成してください。
